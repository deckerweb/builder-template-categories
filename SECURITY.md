# Security policy / Sicherheitsrichtlinie

> Development of Builder Template Categories ended with version 1.9.0. The plugin is outdated: WordPress and modern builders now cover its original tasks, and workflows have changed. Only security updates may be released if needed, and no later than December 31, 2027.

> Die Entwicklung von Builder Template Categories wurde mit Version 1.9.0 eingestellt. Das Plugin ist überholt: Seine ursprünglichen Aufgaben übernehmen heute WordPress und moderne Builder; zugleich haben sich die Arbeitsabläufe verändert. Falls nötig, erscheinen ausschließlich Sicherheitsupdates — längstens bis zum 31.12.2027.

## Supported version

Only the latest 1.9.x security release is eligible for security fixes, if necessary, until December 31, 2027. This is a maximum maintenance period, not a promise of updates or compatibility maintenance. No security maintenance is planned after that date.

## Report privately

Use [GitHub private vulnerability reporting](https://github.com/deckerweb/builder-template-categories/security/advisories/new). If private reporting is unavailable, contact David Decker through [the contact page](https://deckerweb.de/kontakt/) and request a private channel before sharing exploit details. Do not post credentials, personal data or working exploits in a public issue.

## Vertraulich melden

Nutze [GitHubs vertrauliche Meldung](https://github.com/deckerweb/builder-template-categories/security/advisories/new). Falls sie nicht verfügbar ist, kontaktiere David Decker über die [Kontaktseite](https://deckerweb.de/kontakt/) und frage zuerst nach einem vertraulichen Kanal. Keine Zugangsdaten, personenbezogenen Daten oder funktionierenden Exploits öffentlich einstellen.
